Cobblemon Radar is a utility mod for **Minecraft** that enhances the gameplay experience of **Cobblemon** by allowing players to locate and track nearby Pokémon in real time using a customizable radar system.

---

## ✨ Features

- Pokémon name search  
- Real-time visual tracking beams  
- Advanced filtering system:
  - Legendary / Mythical / Ultra Beast  
  - Shiny Pokémon  
  - Hidden Abilities  
  - Uncaught Pokémon  
  - Natures  
  - Genders  
- Clean in-game radar overlay  
- Efficient and lightweight client-side design

## 🛠️ How It Works

Cobblemon Radar scans nearby Pokémon entities and displays them through a radar-style UI. When a target matches your selected filters, a visual beam is rendered pointing directly to it.

## 🧪 Compatibility

Tested with:

- Cobblemon (standard modded environments)
- Cobbleverse (singleplayer & multiplayer)
- Minecraft singleplayer & multiplayer

---

## ⚠️ Multiplayer Notes

- Hidden Ability and Nature filters fully work in singleplayer  
- On multiplayer servers, these filters require the mod to be installed server-side  
- All other radar features are fully client-side  
- Player-owned Pokémon and other trainers’ Pokémon are not tracked  

---

## 🧭 Controls

- **Delete** → Open radar menu  
- Use search fields to filter Pokémon by name or nature  
- Use checkboxes to enable specific filters  
- Use Gender toggle to filter results  
- Click **Apply** to update radar  

---

## 📦 Installation

1. Install Fabric Loader for your Minecraft version  
2. Install Cobblemon  
3. Place the mod `.jar` file into your `mods` folder  
4. Launch the game
